FAQ

Frequently asked questions about Java & Stuff.

What is Java & Stuff? General

Java & Stuff is a curated modpack designed to recreate the Actions & Stuff experience on Minecraft Java Edition.

How do I install the modpack? Install

Download the latest version, then follow these steps:

  1. Install Fabric Loader for your Minecraft version.
  2. Place the downloaded .jar files into your mods/ folder.
  3. Launch Minecraft using the Fabric profile.
Which Minecraft versions are supported? Compatibility

The modpack is currently tuned for the latest supported release. Check the Versions tab on the main page for the full compatibility matrix.

Does this work with Fabric and Forge? Compatibility

It is built exclusively for Fabric. Some mods may have Forge equivalents, but compatibility is not guaranteed and is unsupported.

If you're on Forge, consider looking for a Forge-native alternative modpack instead.
Where can I report bugs? Community

You can report issues in two places:

  • Issue Tracker — for reproducible bugs with steps to reproduce.
  • Community Discord — for general weirdness or quick questions (link on the main page).
Can I use this on a server? Compatibility

Server compatibility varies by mod. To run a server:

  • Check each mod's page for a server-side tag.
  • Ensure the server runs the exact same mod versions as the client.
  • Client-only mods (e.g. shaders, HUD mods) can usually be omitted server-side.
How often is the pack updated? Updates

Updates are released as new versions of the modpack or its dependencies become available. There's no fixed schedule — follow the project on Modrinth or join the Discord to get notified.

Can I suggest a mod to include? Community

Yes! Suggestions are welcome via the community channels. When suggesting, it helps to include:

  • The mod name and Modrinth/CurseForge link.
  • Why it fits the Actions & Stuff experience.
  • Whether it has a Fabric version.
Why is the download page separate? General

The download page provides a simplified interface focused on picking a platform and starting the download — keeping it separate avoids cluttering the main project page.

Where can I find more information? General

Check these resources:

  • Main page — overview, screenshots, and version info.
  • Project repository — full changelog and source.
  • Discord — community discussion and announcements.
